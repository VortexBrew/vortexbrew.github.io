# PS4 13.50 GoldHEN Jailbreak Station

A self-hosted web host for jailbreaking PlayStation 4 consoles on firmware
`13.02` , `13.04` , `13.50` and `13.52` and also `14.00` jailbreak will be added soon. Press **START JAILBREAK** and the browser
runs the WebKit + kernel chain, loads GoldHEN, and unlocks a payloads menu for
fan threshold, firmware spoofing, FTP, custom `.bin` payloads and more.

## Usage
1. Open the site in the PS4 browser.
2. Clear cookies and website data
3. Press **START JAILBREAK**. If it fails, reboot and retry.
4. Use **PAYLOADS** once GoldHEN is working.

## Notes
- Console and payload menu must be on the same network.
- Fan threshold and firmware spoof are also available natively in
  GoldHEN Settings for some versions(PS button → GoldHEN Settings).
